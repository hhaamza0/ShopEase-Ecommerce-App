# 🛍️ ShopEase – Flutter E-Commerce App

ShopEase is a mobile e-commerce application developed using Flutter and Dart as part of a Human-Computer Interaction (HCI) university project.

The project focuses on creating a simple, user-friendly shopping experience with clean UI design and smooth navigation.

## ✨ Features

- Browse six sample products.
- Search products by name.
- Filter products by category.
- View product details and descriptions.
- Add products to the shopping cart.
- Increase and decrease product quantities.
- Remove items from the cart.
- View cart subtotal.
- Order confirmation screen with generated order number.

## 🛠️ Technologies

- Flutter
- Dart
- Material Design 3

## 📱 Application Screens

1. Home Page
2. Product Details Page
3. Shopping Cart Page
4. Order Confirmation Page

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Android Studio or Visual Studio Code
- Android Emulator or Physical Device

### Installation

```bash
git clone https://github.com/hhaamza0/ShopEase-Ecommerce-App.git
```

```bash
cd ShopEase-Ecommerce-App
```

```bash
flutter pub get
```

```bash
flutter run
```
