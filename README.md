# ShopEase - HCI Flutter E-Commerce Project

This project implements the four required pages from the HCI project description:

1. Products Home Page
2. Product Details Page
3. Shopping Cart Page
4. Order Confirmation Page

Navigation:
Products Home -> Product Details -> Shopping Cart -> Order Confirmation

## Run
1. Install Flutter.
2. Open this folder in VS Code or Android Studio.
3. Run:
   flutter pub get
4. Then:
   flutter run

The app uses static product data and network images. No backend/database is required by the provided project description.
